# 에셋허브 (Asset Hub) — PRD

## 1. 프로젝트 개요

- **서비스명:** 에셋허브
- **서비스 유형:** 무료 이미지·디자인 에셋 제공 사이트 탐색 서비스
- **제품 형태:** 브라우저에서 실행하는 웹 MVP
- **목적:** 사용자가 필요한 에셋 유형이나 검색어를 바탕으로 관련 에셋 제공 사이트를 찾고, 각 사이트의 상세 정보와 원본 주소를 확인할 수 있도록 돕는다.
- **핵심 원칙:** 에셋 파일 자체를 서비스에서 제공하거나 내려받게 하는 것이 아니라, 에셋을 제공하는 외부 사이트를 탐색하고 연결한다.

## 2. 주요 사용자

무료 사진, 일러스트, 아이콘, 폰트, 벡터 및 UI 키트 등을 제공하는 사이트를 찾고, 해당 사이트의 이용 정보를 확인하려는 사용자.

## 3. 서비스 범위

### 포함 기능

- 홈 화면에서 주요 에셋 카테고리와 추천 사이트 확인
- 키워드로 에셋 사이트 검색
- 카테고리별 사이트 필터링
- 검색 결과 정렬
- 사이트별 상세 정보 확인
- 원본 사이트 새 창으로 이동
- 관심 사이트 즐겨찾기 저장 및 해제
- 저장한 사이트 목록 확인

### 현재 MVP 범위에서 제외된 기능

- 에셋 이미지·폰트 등의 파일을 직접 제공하거나 다운로드하는 기능
- 외부 사이트의 에셋을 서비스 내부에서 미리보기 또는 편집하는 기능
- 회원가입, 로그인 및 서버 기반 계정 동기화
- 사이트 이용 약관이나 라이선스의 자동 판정 및 보증

## 4. 화면 및 기능 요구사항

### 4.1 홈 화면

- 서비스명과 서비스 설명을 표시한다.
- 핵심 소개 문구와 **에셋 탐색하기** 버튼을 제공한다.
- 사진, 일러스트, 아이콘, 폰트, 벡터, UI 키트의 카테고리 바로가기를 제공한다.
- 추천 사이트 영역을 제공한다.
- 빠른 검색 입력창과 검색 버튼을 제공한다.
- 카테고리 바로가기 선택 시 탐색 화면으로 이동하고 해당 카테고리를 적용한다.
- 빠른 검색 실행 시 탐색 화면으로 이동하고 입력한 검색어를 적용한다.

### 4.2 탐색 및 검색 화면

- 검색어 입력창을 제공한다.
- 카테고리 필터를 제공한다: 전체, 사진, 일러스트, 아이콘, 폰트, 벡터, UI 키트.
- 검색어와 선택한 카테고리에 맞는 사이트 목록을 표시한다.
- 검색 대상에는 사이트명, 제공 유형, 설명, 태그, 키워드, 별칭이 포함된다.
- 검색 결과 수를 표시한다.
- 정렬 옵션을 제공한다: 관련도순, 사이트명순.
- 결과가 없으면 안내 문구와 조건 초기화 버튼을 표시한다.
- 사이트 카드에서 사이트명, 유형, 태그 및 상세 보기 기능을 제공한다.
- 사이트 카드에서 즐겨찾기 저장 및 해제를 할 수 있다.

### 4.3 사이트 상세 화면

- 선택한 사이트의 이름, 설명, 제공 유형, 태그 및 원본 주소를 표시한다.
- 무료 이용 범위 정보를 표시한다.
- **원본 사이트 열기** 링크를 제공하며 외부 사이트를 새 창으로 연다.
- 상업적 이용, 수정, 출처 표기 등 구체적인 라이선스 조건은 원본 사이트의 공식 안내에서 확인하도록 고지한다.
- 상세 화면에서도 즐겨찾기 저장 및 해제를 할 수 있다.
- 탐색 목록으로 돌아가는 기능을 제공한다.

### 4.4 저장 목록 화면

- 사용자가 저장한 사이트 목록을 표시한다.
- 저장된 사이트 수를 표시한다.
- 저장된 사이트의 즐겨찾기를 해제할 수 있다.
- 사이트 상세 화면으로 이동할 수 있다.
- 저장한 사이트가 없으면 빈 목록 안내와 탐색 화면 이동 버튼을 표시한다.

### 4.5 공통 내비게이션

- 하단 탭 메뉴에서 홈, 탐색, 저장 목록 화면으로 이동할 수 있다.
- 저장 목록 탭에는 저장된 사이트 수를 표시한다.

## 5. 데이터 요구사항

사이트 데이터는 `data/asset_hub_data.json` 파일에서 불러온다.

현재 화면과 기능에서 사용하는 데이터 항목은 다음과 같다.

| 항목 | 용도 |
|---|---|
| `name` | 사이트명 및 검색 |
| `category` | 카테고리 필터 및 제공 유형 표시 |
| `description` | 사이트 설명 및 무료 이용 범위 표시 |
| `url` | 원본 사이트 연결 및 주소 표시 |
| `source` | 사이트 태그 구성 |
| `keywords` | 검색어 매칭 |
| `aliases` | 별칭 검색 지원 |

데이터의 카테고리 값은 화면에서 사용하는 한글 카테고리명으로 변환한다. 현재 지원 카테고리는 사진, 일러스트, 아이콘, 폰트, 벡터, UI 키트이다.

## 6. 저장 및 상태 관리

- 즐겨찾기 데이터는 브라우저의 `localStorage`에 `assetFavorites` 키로 저장한다.
- 저장한 사이트는 동일한 브라우저 환경에서 다시 접속했을 때 목록에 반영된다.
- 서버 계정이나 다른 기기와 즐겨찾기를 동기화하지 않는다.
- 사이트 데이터 파일을 불러오지 못하면 오류 안내를 표시한다.

## 7. 비기능 요구사항 및 안내

- 별도의 회원가입이나 서버 설치 없이 브라우저에서 실행할 수 있는 로컬 MVP를 기준으로 한다.
- 외부 사이트의 최신 이용 조건은 변경될 수 있으므로, 사용 전 원본 사이트에서 라이선스를 확인해야 한다.
- 에셋허브는 사이트 탐색을 돕는 참고 정보를 제공하며, 원본 사이트의 라이선스나 이용 가능 여부를 보증하지 않는다.

## 8. 현재 구현 기준 및 유의사항

- 본 PRD는 현재 `index.html`에 구성된 화면과 메뉴를 기준으로 작성했으며, 실제 동작 설명은 연결된 `js/app.js`의 구현을 반영한다.
- 추천 사이트 영역은 현재 코드에 지정된 사이트명(Unsplash, unDraw, Heroicons)을 기준으로 표시한다.
- 정렬의 관련도순은 별도의 점수 계산이 아니라 데이터의 기본 순서를 유지한다.
- 상세 화면의 대표 이미지 영역은 현재 이미지 대신 자리 표시 문구로 구성되어 있다.
- 라이선스 안내는 원본 사이트 확인을 유도하는 안내이며, 사이트별 라이선스 정보를 자동 검증하는 기능은 아니다.

## 9. 프로젝트 실행 방법

1. ZIP 압축을 해제한다.
2. 압축 해제한 폴더에서 `index.html`을 브라우저로 연다.
3. 홈, 탐색, 사이트 상세, 저장 목록 화면을 확인한다.
4. 검색, 카테고리 필터, 정렬, 상세 보기, 원본 사이트 열기, 즐겨찾기 저장 및 해제를 테스트한다.
