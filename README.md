# 에셋허브 (Asset Hub) — PRD

## 1. 프로젝트 개요

- **서비스명:** 에셋허브 (Asset Hub)
- **서비스 유형:** 무료 이미지·디자인 에셋 제공 사이트 탐색 서비스
- **제품 형태:** 웹 기반 MVP
- **목적:** 사용자가 원하는 에셋 유형이나 검색어를 기준으로 관련 사이트를 탐색하고, 사이트별 기본 정보와 원본 사이트 주소를 확인할 수 있도록 지원한다.
- **핵심 방향:** 에셋 파일을 서비스 내부에서 직접 제공하는 것이 아니라, 에셋을 제공하는 외부 사이트를 찾아 연결한다.

## 2. 주요 사용자

무료 사진, 일러스트, 아이콘, 폰트, 벡터, UI 키트 등을 제공하는 사이트를 찾고 이용 정보를 확인하려는 사용자.

## 3. 서비스 범위

### 3.1 포함 기능

- 홈 화면에서 에셋 카테고리와 추천 사이트 확인
- 키워드로 사이트 검색
- 카테고리별 사이트 필터링
- 검색 결과 정렬
- 사이트별 상세 정보 확인
- 원본 사이트 새 창으로 이동
- 즐겨찾기 사이트 저장 및 해제
- 저장한 사이트 목록 확인
- 하단 탭 메뉴를 통한 주요 화면 이동

### 3.2 현재 범위에 포함되지 않는 기능

- 이미지·폰트 등 에셋 파일의 직접 다운로드 및 제공
- 외부 사이트 콘텐츠의 서비스 내부 미리보기 또는 편집
- 회원가입 및 로그인
- 서버 기반 즐겨찾기 저장 및 기기 간 동기화
- 사이트별 라이선스 조건의 자동 판정 및 보증

## 4. 화면 및 기능 요구사항

### 4.1 홈 화면

- 서비스명과 서비스 소개 문구를 표시한다.
- **에셋 탐색하기** 버튼으로 탐색 화면에 이동한다.
- 사진, 일러스트, 아이콘, 폰트, 벡터, UI 키트 카테고리 바로가기를 제공한다.
- 추천 사이트 영역을 제공한다.
  - 현재 코드에서 추천 대상으로 지정한 사이트명은 Unsplash, unDraw, Heroicons이다.
- 빠른 검색 입력창과 검색 버튼을 제공한다.
- 카테고리 바로가기를 선택하면 탐색 화면으로 이동하고 해당 카테고리를 적용한다.
- 빠른 검색을 실행하면 탐색 화면으로 이동하고 입력한 검색어를 적용한다.

### 4.2 탐색 화면

- 검색어 입력창을 제공한다.
- 카테고리 필터를 제공한다.
  - 전체, 사진, 일러스트, 아이콘, 폰트, 벡터, UI 키트
- 검색어와 선택한 카테고리에 맞는 사이트 목록을 표시한다.
- 검색 대상은 사이트명, 제공 유형, 설명, 태그, 키워드, 별칭이다.
- 검색어 입력 시 결과를 갱신한다.
- 검색 결과 수를 표시한다.
- 정렬 옵션을 제공한다.
  - 관련도순: 데이터의 기본 순서를 유지한다.
  - 사이트명순: 사이트명을 기준으로 오름차순 정렬한다.
- 검색 결과가 없으면 결과 없음 안내와 조건 초기화 버튼을 표시한다.
- 사이트 카드에는 사이트명, 제공 유형, 태그, 상세 보기 버튼을 표시한다.
- 사이트 카드에서 즐겨찾기를 저장하거나 해제할 수 있다.

### 4.3 사이트 상세 화면

- 선택한 사이트의 이름, 설명, 제공 유형, 태그 및 원본 주소를 표시한다.
- 데이터의 설명을 무료 이용 범위 항목에도 표시한다.
- **원본 사이트 열기** 버튼을 통해 외부 사이트를 새 창으로 연다.
- 상세 화면에서 즐겨찾기를 저장하거나 해제할 수 있다.
- **탐색 목록으로** 버튼으로 탐색 화면에 돌아갈 수 있다.
- 대표 이미지 영역은 현재 실제 이미지가 아닌 자리 표시 문구로 구성한다.
- 라이선스의 구체적인 조건은 원본 사이트의 공식 안내에서 확인하도록 고지한다.

### 4.4 저장 목록 화면

- 사용자가 즐겨찾기로 저장한 사이트를 표시한다.
- 저장된 사이트 수를 표시한다.
- 저장된 사이트의 즐겨찾기를 해제할 수 있다.
- 사이트 상세 화면으로 이동할 수 있다.
- 저장한 사이트가 없으면 빈 목록 안내와 탐색 화면 이동 버튼을 표시한다.

### 4.5 공통 내비게이션

- 화면 하단 탭 메뉴에서 홈, 탐색, 저장 목록으로 이동할 수 있다.
- 상세 화면에서는 탐색 탭이 활성화된 상태로 표시된다.
- 저장 목록 탭에는 저장된 사이트 수를 표시한다.

## 5. 데이터 요구사항

사이트 목록은 `data/asset_hub_data.json` 파일에서 불러온다.

| 원본 데이터 항목 | 화면 및 기능에서의 용도 |
|---|---|
| `name` | 사이트명 표시 및 검색 |
| `category` | 카테고리 변환, 필터링, 제공 유형 표시 |
| `description` | 사이트 설명 및 무료 이용 범위 표시 |
| `url` | 원본 사이트 연결 및 주소 표시 |
| `source` | 사이트 태그 구성 |
| `keywords` | 검색어 매칭 |
| `aliases` | 별칭 검색 지원 |

- 원본 카테고리 값은 화면에서 사용하는 한글 카테고리명으로 변환한다.
- 현재 지원 카테고리는 사진, 일러스트, 아이콘, 폰트, 벡터, UI 키트이다.
- 각 사이트의 내부 식별자는 카테고리, 사이트명, 데이터 배열 순번을 조합해 생성한다.
- 검색은 검색 대상 문자열에 입력한 검색어가 포함되는지를 기준으로 처리한다.

## 6. 저장 및 상태 관리

- 즐겨찾기 목록은 브라우저 `localStorage`의 `assetFavorites` 키에 저장한다.
- 저장된 값은 사이트 식별자 목록이다.
- 즐겨찾기 변경 시 탐색 목록, 저장 목록, 상세 화면의 저장 버튼 및 하단 저장 개수를 갱신한다.
- 저장 정보는 현재 브라우저 환경에 저장되며 서버나 다른 기기와 동기화되지 않는다.

## 7. 비기능 요구사항 및 서비스 안내

- 별도의 회원가입 없이 이용할 수 있는 MVP를 기준으로 한다.
- 사이트 데이터는 프로젝트 내부 JSON 파일에서 불러온다.
- 외부 사이트의 정보와 라이선스는 변경될 수 있으므로 실제 이용 전 원본 사이트에서 최신 조건을 확인해야 한다.
- 에셋허브는 사이트 탐색을 위한 참고 정보를 제공하며, 원본 사이트의 라이선스나 이용 가능 여부를 보증하지 않는다.

## 8. 현재 구현 기준 및 제한사항

- 본 문서는 현재 프로젝트의 `index.html` 화면 구성과 연결된 `js/app.js` 동작을 기준으로 작성했다.
- 추천 사이트는 코드에 지정된 이름(Unsplash, unDraw, Heroicons)과 데이터의 사이트명이 일치하는 경우 표시된다.
- 관련도순은 별도의 검색 점수를 계산하지 않고 데이터의 기본 순서를 유지한다.
- 사이트 카드의 썸네일 및 상세 화면의 대표 이미지 영역은 현재 자리 표시 문구로 구성되어 있다.
- 상세 화면의 라이선스 안내는 원본 사이트 확인을 유도하는 문구이며, 라이선스를 자동으로 확인하는 기능은 없다.
- 데이터 파일을 불러오지 못하면 오류 안내창을 표시한다.

## 9. 프로젝트 실행 방법

`index.html`은 JSON 데이터를 `fetch()`로 불러오므로, 브라우저에서 파일을 직접 여는 방식(`file://`)보다 로컬 웹 서버를 통해 실행하는 것을 기준으로 한다.

1. ZIP 파일의 압축을 해제한다.
2. 프로젝트 폴더를 Visual Studio Code 등 편집기에서 연다.
3. Live Server 등의 로컬 웹 서버로 `index.html`을 실행한다.
4. 홈, 탐색, 사이트 상세, 저장 목록 화면에서 검색·필터·정렬·즐겨찾기 기능을 확인한다.
