실행 방법
1. ZIP 압축을 해제합니다.
2. project 폴더 안의 index.html을 더블 클릭하여 브라우저에서 엽니다.
3. 홈 / 탐색 / 사이트 상세 / 저장 목록 메뉴로 화면을 전환합니다.
4. 검색, 카테고리 필터, 상세 보기, 원본 사이트 열기, 즐겨찾기 저장/해제를 테스트할 수 있습니다.

참고
- 그레이톤 로우파이 와이어프레임입니다.
- 별도 서버나 설치 없이 브라우저에서 실행할 수 있습니다.
- 즐겨찾기는 브라우저 localStorage에 저장됩니다.
- 사이트 정보와 링크는 예시이며, 실제 사용 전 각 원본 사이트의 최신 이용 약관과 라이선스를 확인하세요.
